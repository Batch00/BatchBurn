# BatchBurn

A personal workout tracking and analytics app for runners. Log runs, 
cross training, and races. Track shoe mileage, set goals, and visualize 
performance trends — all from a mobile-first dark athletic interface.

**Live app**: https://batchburn.batch-apps.com  
**Part of the [Batch ecosystem](https://www.batch-apps.com)**

---

## Features
- **Activity Logging** — Log runs with distance, duration, pace, type, 
  shoe, and notes. Log cross training: bike, walk, stair master, swim, 
  strength, yoga.
- **Dashboard** — WTD/MTD/YTD mileage KPIs, weekly mileage chart with 
  activity type filters and cross-filtering, recent activity feed.
- **Analytics** — Pace trend, mileage by run type, run type donut chart, 
  personal bests, cross training breakdown.
- **Shoe Tracker** — Track mileage per shoe, price per mile, retirement 
  status, and lifespan warnings at 350/400 miles.
- **Race Log** — Log race results with automatic PR detection.
- **Goals** — Set weekly, monthly, or yearly mileage targets with 
  progress tracking.
- **Strava Sync** — OAuth integration for automatic activity import 
  from Strava and Garmin (coming soon).
- **Invite Only** — Access gated by invite code. Demo account available.
- **PWA** — Installable on iOS and Android as a home screen app.

## Tech Stack
- Next.js 15 (App Router, TypeScript)
- Supabase (PostgreSQL, Auth, RLS)
- Tailwind CSS + shadcn/ui
- Recharts
- React Hook Form + Zod
